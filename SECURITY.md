# Security Policy

## Scope

This repository is a static frontend prototype and does not process accounts, payments, or private user data. It must not be presented as a production commerce system.

## Reporting a concern

Do not publish sensitive details in a public issue. Report suspected vulnerabilities or accidental secret exposure privately to the repository owner, Brajesh Kumar (`@brajesh31`), through the contact method available on the GitHub profile.

Please include affected files, reproduction steps, impact, and a suggested mitigation when safe to do so. Do not include credentials or personal data in the report.

## Safe development

Keep third-party URLs and assets intentional, use integrity metadata where supported, and never place API keys, tokens, payment details, or customer information in this static site.
