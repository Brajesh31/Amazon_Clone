# Development

Edit the three source files directly:

- `index.html` for sections, labels, links, and image references.
- `amazone.css` for layout, typography, colors, and responsive behavior.
- `amazone.js` for carousel and horizontal-scroll interactions.

After every change, reload the site through a local server and inspect the browser console. Keep selectors stable, avoid inline behavior for new features, and test with keyboard navigation and a narrow viewport.
