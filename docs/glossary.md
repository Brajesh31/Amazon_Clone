# 📖 Project Glossary

This glossary defines technical terms as they apply to this repository. It is intended to help contributors understand the current implementation without implying that future systems already exist.

| Term | Definition in this project |
|---|---|
| Static storefront | A browser page delivered as files rather than generated by an application backend |
| HTML | The markup language used to describe the page structure |
| CSS | The stylesheet language used to control visual presentation and responsive layout |
| Vanilla JavaScript | Browser-native JavaScript without a frontend framework |
| DOM | The browser's Document Object Model representation of the HTML document |
| Hero carousel | The large promotional image area with previous and next controls |
| Active slide | The hero image currently selected for display |
| Carousel index | The local integer used to identify the active slide |
| Product rail | A horizontally scrollable row of product images or cards |
| `scrollLeft` | The horizontal scroll offset of an element |
| `scrollWidth` | The total width of an element's content, including overflow |
| `clientWidth` | The inner visible width of an element |
| Wheel event | A browser event representing wheel or similar scrolling input |
| `deltaX` | Horizontal component of a wheel event |
| `deltaY` | Vertical component of a wheel event |
| Event listener | A callback registered to respond to a browser event |
| `preventDefault` | A method that cancels a browser event's default action when cancellation is allowed |
| Responsive breakpoint | A viewport width at which a CSS media query changes layout rules |
| Media query | A CSS condition that applies styles based on viewport or device characteristics |
| Local asset | A file referenced by a path within the repository or deployed static site |
| External resource | A resource loaded from a host outside this repository |
| Placeholder link | An anchor whose destination does not implement the expected product or category journey |
| Alternative text | Text that communicates the purpose or content of an image to assistive technology |
| Landmark | A semantic page region, such as navigation or main content, that helps users navigate |
| Accessible name | The name exposed by a control to assistive technology |
| Focus indicator | A visible cue identifying the currently keyboard-focused element |
| Persistence | Retaining data beyond the current page runtime |
| API | A defined interface for software components or services to exchange data |
| Backend | Server-side application logic and data services |
| Database | A persistent data store; none is present in the current project |
| Authentication | Verification of a user's identity |
| Authorization | Determining whether an identified user may perform an action |
| CI | Continuous integration, automated checks run against repository changes |
| Test runner | A tool that discovers and executes automated tests |
| Mock DOM | A simplified test representation of browser elements and events |
| Static hosting | Serving HTML, CSS, JavaScript, and assets without a server-side application |
| ADR | Architecture Decision Record, documenting a design decision and its rationale |
| Threat boundary | The point where data or control crosses between components with different trust levels |
| CSP | Content Security Policy, a browser-enforced response policy controlling permitted resource sources |
| MIT License | A permissive open-source software licence; it does not grant rights to unrelated third-party assets |
| Asset inventory | A record of referenced media files, sources, rights, and current availability |
| Technical debt | A future maintenance cost caused by a shortcut or incomplete design decision |
| Regression | A previously working behaviour becoming broken after a change |

## Usage note

Use these definitions consistently in issues, pull requests, diagrams, and documentation. If a new term becomes important to the project, add a concise definition and link to the document that explains the implementation.
