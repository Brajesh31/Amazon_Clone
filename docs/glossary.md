# 📖 Glossary

| Term | Meaning in this repository |
|---|---|
| Static storefront | A page whose content is delivered as files rather than generated from an application backend |
| Hero carousel | The large promotional image area with previous and next controls |
| Product rail | A horizontally scrollable row of product images or cards |
| Active slide | The carousel image currently shown |
| DOM | The browser's Document Object Model representation of the HTML |
| `scrollLeft` | The horizontal scroll offset of an element |
| `scrollWidth` | The total width of an element's scrollable content |
| `clientWidth` | The inner visible width of an element |
| Wheel event | Browser input event produced by a mouse wheel or similar device |
| Responsive breakpoint | A viewport width at which CSS rules change |
| Local asset | A file referenced by a relative path within the repository or deployed site |
| External resource | An image, font, or stylesheet loaded from another host |
| Placeholder link | An anchor that does not lead to a fully implemented product or category destination |
| Persistence | Retaining data beyond the current page runtime or browser session |
| API | A defined interface for communication between software components or services |
| ADR | Architecture Decision Record, a document recording a design decision and its rationale |
| CI | Continuous integration, automated checks run against repository changes |
| Accessibility | Designing the interface so people with differing abilities can use it |
