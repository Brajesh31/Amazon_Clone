# Roadmap

This roadmap distinguishes the current frontend prototype from future product scope.

## Immediate quality work

- [x] Add automated tests for carousel and horizontal scrolling behaviour.
- [x] Add a static HTML and local-reference checker.
- [x] Document unresolved local assets and current non-functional controls.
- [ ] Supply licensed replacements for the missing local image references.
- [ ] Complete browser-based responsive and accessibility review.
- [ ] Consider changing carousel anchor controls to native buttons.

## Frontend enhancements

- Extract product card content into a small local data structure.
- Add actual local search/filter behaviour if it remains a static demonstration.
- Provide image fallbacks and more descriptive alternative text.
- Refine narrow-screen navigation and layout.

## Only if the project becomes a commerce application

A real store requires a backend, catalog and inventory model, authentication and authorization, cart persistence, order lifecycle, payment provider integration, fraud controls, privacy policy, operational monitoring, and security review. These are not incremental UI-only features and should be designed as a separate system.
