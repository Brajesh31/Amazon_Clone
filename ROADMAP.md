# Roadmap

## Near term

- Add reliable responsive breakpoints and keyboard-accessible carousel controls.
- Add local fallback assets and meaningful alternative text for every image.
- Separate product content from markup into a small data model.

## Future

- Add filtering and search behavior without requiring a backend.
- Introduce automated browser checks for carousel and scrolling behavior.
- If this becomes a real commerce application, move catalog, identity, cart, checkout, and payment operations behind a reviewed backend.
