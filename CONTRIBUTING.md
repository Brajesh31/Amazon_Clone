# Contributing

Thank you for helping improve Amazon Clone.

## Before submitting a change

1. Read the README and relevant documentation under `docs/`.
2. Keep the project dependency-free unless a change clearly requires a package.
3. Preserve the educational, static-prototype scope.
4. Do not commit credentials, private data, generated build output, or unlicensed assets.

## Making changes

Make focused edits to `index.html`, `amazone.css`, or `amazone.js`. Keep JavaScript selectors synchronized with the markup and use semantic HTML and descriptive `alt` text for new images. Test the page through a local HTTP server in a current desktop browser and check keyboard navigation and responsive layouts.

## Pull requests

Describe the user-visible change, list manual checks performed, and include screenshots for visual changes. Explain any new external asset or service and provide its license or source.
